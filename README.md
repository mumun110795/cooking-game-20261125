Warung Senja is an original Indonesian warung cooking game drawn entirely in code on a 2D canvas. Customers arrive at the counter with order tickets — nasi goreng, mie goreng, sate ayam, bakso sapi, gado-gado and es teh manis — each with a draining patience bar. You click the ingredient bins on the counter to stack a dish onto the plate, send it to the wok, grill or drink station and watch the doneness timer, move the finished dish to the pass, then serve it to the matching ticket before patience runs out to earn coins and build a combo. A 150-second shift clock ends the day, and the game-over screen shows your score with a restart button. No network loads, no external assets: every sprite, sound blip and sign is generated by the game's own code.
